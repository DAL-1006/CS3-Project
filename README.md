# Project Description: 
The program can display information about a book in a library. This serves to promote convenience and accessibility of library services.

The program allows you to change and can output the name of a book, number of copies total, number of copies available, number of borrowed copies at the moment, and the name of a borrower. It also will say if the book asked for isn't in the library's list of books.

The name of a book involves a book class, its "name" attribute, and the library class, and its "list of books" attribute.

The number of copies total involves a book class and its "copies" attribute

The number of copies available involves a book class, its "copies" attribute, and a student class, and its "borrow" method

The number of copies borrowed involves a book class, its "copies" attribute, and a student class, and its "borrow" method 

The name of a borrower involves a student class and its "name" attribute
